# Analysis notes

One markdown file per trading session, `YYYY-MM-DD.md`, written by Claude in
the daily refresh workflow and committed here.

Each note leads with volume — which names traded unusually and whether
participation backed the move — then valuation, reading every multiple against
its peer group rather than in isolation. Notes say what changed since the
previous one instead of restating the board, and a quiet day is allowed to be
four lines.

These are descriptive analyses of published data. They are not investment
advice, and they contain no recommendations or price targets.
